# retail-purchase-frequency-analysis
This project uses MLE to analyze Amazon &amp; Barnes &amp; Noble transactions. To fix severe data overdispersion, we benchmarked Poisson, NBD, Poisson Regression, &amp; NBD Regression. NBD Regression performed best across LL, AIC, &amp; BIC metrics by merging demographic covariates with a dispersion parameter. Region, Race, &amp; Country are vital predictors.
